# 🌐 Portfolio — Gustavo Rocha

Portfólio pessoal desenvolvido para apresentar projetos práticos, formação acadêmica, habilidades técnicas e experiências extracurriculares. Desenvolvido com foco em uma estética técnica/minimalista inspirada em folhas milimetradas de engenharia, tipografia clara e arquitetura modular tipada com **TypeScript**.

🔗 **Acesse online:** [pachecw.github.io](https://pachecw.github.io/)

---

## 🎯 Sobre o Projeto

Este projeto foi construído do zero com o objetivo de servir como hub profissional centralizado para processos seletivos e candidaturas a vagas de estágio em Tecnologia e Engenharia.

Além da identidade visual moderna e responsiva, o desenvolvimento deste portfólio marcou meu primeiro contato prático com **TypeScript**, explorando tipagem estática, interfaces e contratos de dados (para estruturar projetos, competências e experiências) e maior previsibilidade no front-end.

---

## 🛠️ Tecnologias Utilizadas

- **TypeScript:** Tipagem estática, estruturação de dados e robustez no desenvolvimento.
- **HTML5 & CSS3:** Estilização com layout estruturado, background customizado em grid e responsividade.
- **Vite / Ferramenta de Build:** Ambiente de desenvolvimento rápido e geração de bundle otimizado.
- **GitHub Pages:** Deploy automatizado e hospedagem contínua.
